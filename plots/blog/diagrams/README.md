# Blog schematics (hand-authored SVG)

Explanatory schematics for the **"Genomic Language Model Optimization"** blog post,
tracked in [Open-Athena/marin-dna#368](https://github.com/Open-Athena/marin-dna/issues/368).
These are **hand-authored** SVGs (not generated by a recipe) — companions to the
matplotlib figures in the parent directory.

| File | What it shows |
|---|---|
| `data_provenance_final.svg` | The five region datasets + the two build pipelines (annotation vs projection), with token bars and 🤗 links to each source dataset. |
| `mini_scaling_ladder.svg` | Scaling-ladder proportional mix — one mix shared by all 8 sizes (§ Figs 5–8). |
| `mini_fig9_mixture.svg` | The upstream-reweight experiment (§ Fig 9). |
| `mini_m5.1_lineage.svg` | Continued-training lineage: uniform 3-region → +ncRNA +Enhancer → m5.1 (§ Fig 10). |

The **eval-apparatus** schematic is still a draft and lives on the issue only (not committed here yet).

## Conventions

- **Palette** = the blog's `EARTH_QUAL` qualitative palette (`../_style/figure_style.py`).
  Region colors: CDS `#9c4f2f`, Upstream `#2f6f63`, Downstream `#c0883a`, ncRNA `#465c6e`, Enhancer `#6f7d3f`; panel `#f6f0e4`, ink `#1f1e1b`.
- **Token counts** = exact HuggingFace window count × 255 bp (see #368 for the per-dataset table).
- **Mixture proportions** = the `LINEAGE` weights table in `../_mixture_lineage.py`.
- **HF links** in the SVGs are clickable only when the SVG is inlined (not as `<img>` / PNG); the model links are placeholders until the weights are pushed to the Hub.

See issue #368 for the full provenance/methodology and the rendered diagrams.
