01 / Method

From one changed base to a latent response

A sparse autoencoder is the microscope, not the scientific endpoint. The central object is a matched counterfactual: how the feature response changes from the reference allele to the alternate allele.

Matched sequence pair

Extract the same 255-bp genomic context twice, changing only the focal allele. This local counterfactual removes most background-locus variation and aligns directly with variant-effect prediction.

sequence_ref ↔ sequence_alt

What “JumpReLU” means

Each dense model state is projected into a much larger dictionary. A feature stays exactly zero until its learned pre-activation clears a learned threshold—then it “jumps” on.

02 / Synthesis

Three ideas survive the details

The results do not reduce to “SAEs find motifs.” They reveal where the model’s local grammar is strongest, how depth changes the answer, and where biological signal is entangled with composition.

Causal foothold

Splice and stop grammar are real

Acceptor, donor, and stop-creation responses survive untouched-context perturbations, both orientations, multiple dictionaries, and a healthier 25M-activation SAE. These are the strongest mechanistic findings.

Depth matters

There is no globally best layer

The middle layer is strongest for broad consequence discovery; the final layer dominates pathogenicity, complex-trait labels, signed dsQTL direction, and several structured-RNA responses.

Interpret carefully

Composition is signal and confounder

Repeats consume substantial response capacity. A prominent AlphaGenome-associated feature tracks GC/CpG-rich promoter sequence. Statistical association names a direction for investigation—it does not finish the interpretation.

07 / Statistical lens

One association framework, matched to outcome type

We use every eligible variant for discovery. The inferential test changes with the outcome, but the discipline stays fixed: declare the full family, report support and effect sizes, and control FDR within each layer.

Continuous association

Linear effect plus monotonic robustness

Pearson asks whether the relationship is linear; Spearman asks whether it is monotonic and less sensitive to scale. They form separate predeclared BH families.

AUPRC is a benchmark-aligned descriptive effect measure for binary outcomes—not the inferential test. Its chance reference is class prevalence.

08 / What remains

A feature name is a hypothesis

The useful standard is calibrated understanding: what activates a feature, where, on which strand, under which edits, and whether the concept survives a new dictionary.

Do not overclaim

  • Generic synonymous semantics failed to replicate across independent 5M dictionaries.
  • Fine AlphaGenome tissue or cell-type specificity is not established.
  • The positive-only dsQTL pilot tests effect direction, not QTL causality.
  • Correlated feature families can make dozens of IDs represent only a few response dimensions.
  • The 255-bp model can learn local regulatory grammar, not long-range enhancer–promoter interactions.

Next scientific moves

  • Complete signed/default-scorer AlphaGenome analysis and tissue taxonomy.
  • Inspect exact CDS/intron, UTR/CDS, ELS, and PLS boundaries position by position.
  • Advance from UTRs and promoters toward the harder enhancer tier.
  • Rerun fixed biology panels as SAE budgets, layers, sparsity, and seeds improve.
  • Study decoder neighborhoods and co-activation programs—not only single feature IDs.
  • Ablate or clamp a small preregistered set in the base model for causal downstream tests.
